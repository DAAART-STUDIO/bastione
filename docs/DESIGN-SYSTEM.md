# Design System

## Direction

Bastione is designed as a premium editorial hospitality experience.

Visual references:

- contemporary Italian hospitality
- architecture
- luxury restaurant design
- travel editorial
- cinematic photography

The interface should never feel like a generic template.

## Principles

Prioritize:

- photography
- typography
- composition
- whitespace
- hierarchy
- atmosphere
- subtle motion

Avoid:

- excessive cards
- excessive rounded corners
- generic gradients
- excessive shadows
- unnecessary UI
- template-like layouts
