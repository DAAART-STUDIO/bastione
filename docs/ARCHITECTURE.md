# Architecture

## Overview

Bastione is a lightweight static website built with HTML, CSS and vanilla JavaScript.

The project intentionally avoids a frontend framework and does not currently require a build step.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- JavaScript ES Modules
- JSON
- SVG
- WebP
- CSS Custom Properties
- GSAP / ScrollTrigger for selected cinematic interactions
